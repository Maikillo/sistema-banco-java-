# 🏦 Sistema Bancário em Java

Projeto desenvolvido como atividade prática da disciplina **Programação Orientada a Objetos (POO)** no **CEFET-MG - Unidade Campo Belo**.  
Este sistema simula o gerenciamento de contas bancárias, aplicando os principais pilares da POO: **abstração, encapsulamento, herança, polimorfismo e interfaces**.

---

## 📌 Funcionalidades

- Cadastro de **Conta Corrente** e **Conta Poupança**
- Operações financeiras:
  - Depósito
  - Saque (com cheque especial na Conta Corrente)
  - Aplicação de rendimento na Conta Poupança
- Consulta de saldo
- Extrato detalhado da conta
- Histórico de transações com data e hora
- Listagem de todas as contas cadastradas
- Relatório geral do banco (patrimônio total, maior e menor saldo)

---

## 🛠️ Tecnologias Utilizadas

- **Java 21**
- IDE: IntelliJ IDEA / Eclipse (qualquer IDE compatível)
- Entrada e saída de dados via **JOptionPane**
- Estrutura modular com pacotes
